# MTH 314 — Matrix Algebra with Applications

![Python](https://img.shields.io/badge/python-3.9%2B-blue) ![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-orange) ![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

Computational linear algebra with NumPy and SymPy — from Gauss–Jordan elimination to eigendecomposition, SVD and least-squares fitting.

**Course:** MTH 314 — Matrix Algebra with Applications  
**Term:** Spring 2023  
**Institution:** Michigan State University

## Highlights

- **Honors project:** regression analysis of advertising spend vs. sales (TV, radio, newspaper) comparing linear, log and polynomial fits with error analysis.
